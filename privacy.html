Fasting Tracker

Privacy

Fasting Tracker is designed as a local-first web app. Fasting and weight entries are kept on the device where you use the app.

What the app stores

Fasting records, weight entries, targets, preferences, achievements and recovery snapshots are stored in browser/web-app storage on your device. The app itself does not operate a backend database for those records.

Backups

When you choose Export or Backup & Update, the app creates a JSON file for you to save or share. You control where that file goes. Internal recovery snapshots remain in the same local browser storage and are not a substitute for an external backup. Exported JSON backup files are plain text and are not encrypted by Fasting Tracker, so store them somewhere you consider secure.

Network requests

The app downloads its static files and checks version.json from the same website to look for updates. It does not include advertising or analytics code and does not set tracking cookies. The hosting provider may receive ordinary web-request information such as IP address, browser/user-agent and request time under its own privacy practices.

External links

Links to PubMed, NEJM, Johns Hopkins, NIH/NIA and other sources open third-party websites. Those sites have their own privacy practices.

Deleting data

Use Settings → Delete all data to clear the app's local records and recovery snapshots. Clearing browser/site data can also remove local records. Keep an external backup if you want to preserve them.

Safari, Home Screen apps & storage protection

On iPhone and iPad, Safari and an installed Home Screen web app can use separate local storage. Records entered in Safari may therefore not automatically appear in the Home Screen app. Use Export in the copy that contains your data, then Import in the other copy to move it. The app can request persistent browser storage and shows its status in Settings; persistent storage reduces ordinary eviction risk but is not a guarantee and does not replace an external backup.

Public source hosting

The app is intended to be distributed as static files through GitHub Pages. GitHub's own privacy statement applies to its hosting infrastructure.

Browser storage is scoped to the website origin. If this app shares an origin with unrelated web apps, code served from those same-origin pages can potentially access the same browser storage. For a public deployment, a dedicated domain/subdomain or dedicated GitHub Pages origin is preferable.

GitHub General Privacy Statement

Поверителност

Fasting Tracker е проектиран като приложение, което пази данните локално. Записите за гладуване и тегло остават на устройството, на което използвате приложението.

Какво съхранява приложението

Записите за гладуване, тегло, цели, настройки, постижения и възстановителни копия се съхраняват в локалното хранилище на браузъра/уеб приложението. Самото приложение не използва сървърна база данни за тези записи.

Архиви

При Експорт или Архивирай и обнови приложението създава JSON файл, който вие избирате къде да запазите или споделите. Вътрешните възстановителни копия остават в същото локално хранилище и не заменят външен архив. Експортираните JSON архиви са обикновени текстови файлове и не се криптират от Fasting Tracker, затова ги съхранявайте на място, което считате за сигурно.

Мрежови заявки

Приложението изтегля статичните си файлове и проверява version.json от същия сайт за обновявания. Няма рекламен или аналитичен код и не задава проследяващи бисквитки. Хостинг доставчикът може да получава обичайна техническа информация за уеб заявки, например IP адрес, браузър/user-agent и време на заявката, съгласно собствените си правила.

Външни връзки

Връзките към PubMed, NEJM, Johns Hopkins, NIH/NIA и други източници отварят сайтове на трети страни със собствени правила за поверителност.

Изтриване на данни

Използвайте Настройки → Изтрий всички данни, за да изчистите локалните записи и възстановителни копия. Изчистването на данните на браузъра/сайта също може да премахне записите.

Safari, приложение на началния екран и защита на хранилището

На iPhone и iPad Safari и инсталираното уеб приложение на началния екран могат да използват отделни локални хранилища. Затова записи, въведени в Safari, може да не се появят автоматично в приложението на началния екран. Използвайте Експорт в копието, което съдържа данните, а след това Импорт в другото копие. Приложението може да поиска постоянно браузърно хранилище и показва статуса му в Настройки; това намалява риска от обичайно автоматично освобождаване на място, но не е гаранция и не заменя външен архив.

Публичен хостинг

Приложението е предназначено за разпространение като статични файлове чрез GitHub Pages. За инфраструктурата на GitHub важи политиката за поверителност на GitHub.

Хранилището на браузъра е обвързано с произхода на уебсайта. Ако приложението споделя един и същ произход с несвързани уеб приложения, код от тези страници със същия произход потенциално може да има достъп до същото браузърно хранилище. За публично разпространение е за предпочитане отделен домейн/поддомейн или отделен GitHub Pages произход.

GitHub General Privacy Statement

Privacidad

Fasting Tracker está diseñado como una aplicación local. Los registros de ayuno y peso permanecen en el dispositivo donde utilizas la app.

Qué guarda la app

Los registros de ayuno, peso, objetivos, preferencias, logros y copias de recuperación se guardan en el almacenamiento local del navegador/app web. La propia app no utiliza una base de datos de servidor para esos registros.

Copias de seguridad

Al usar Exportar o Copia y actualizar, la app crea un archivo JSON y tú decides dónde guardarlo o compartirlo. Las copias internas de recuperación permanecen en el mismo almacenamiento local y no sustituyen una copia externa. Los archivos JSON exportados son texto sin cifrar; Fasting Tracker no los cifra, así que guárdalos en un lugar que consideres seguro.

Solicitudes de red

La app descarga sus archivos estáticos y consulta version.json en el mismo sitio para buscar actualizaciones. No incluye publicidad ni analítica y no establece cookies de seguimiento. El proveedor de alojamiento puede recibir información técnica normal de las solicitudes web, como dirección IP, navegador/user-agent y hora de la solicitud, según sus propias prácticas.

Enlaces externos

Los enlaces a PubMed, NEJM, Johns Hopkins, NIH/NIA y otras fuentes abren sitios de terceros con sus propias prácticas de privacidad.

Eliminar datos

Usa Ajustes → Eliminar todos los datos para borrar los registros locales y las copias de recuperación. Borrar los datos del navegador/sitio también puede eliminar los registros.

Safari, app de pantalla de inicio y protección del almacenamiento

En iPhone y iPad, Safari y una app web instalada en la pantalla de inicio pueden usar almacenamiento local separado. Por eso, los registros introducidos en Safari pueden no aparecer automáticamente en la app de la pantalla de inicio. Usa Exportar en la copia que contiene tus datos y después Importar en la otra copia. La app puede solicitar almacenamiento persistente del navegador y muestra su estado en Ajustes; esto reduce el riesgo de eliminación automática por presión de espacio, pero no es una garantía ni sustituye una copia externa.

Alojamiento público

La app está pensada para distribuirse como archivos estáticos mediante GitHub Pages. La infraestructura de alojamiento de GitHub está sujeta a su propia declaración de privacidad.

El almacenamiento del navegador está limitado por el origen del sitio web. Si esta app comparte origen con otras aplicaciones web no relacionadas, el código servido desde páginas del mismo origen podría acceder al mismo almacenamiento del navegador. Para una publicación pública es preferible usar un dominio/subdominio dedicado o un origen de GitHub Pages dedicado.
